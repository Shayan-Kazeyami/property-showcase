# Property experiences

A static architectural visualisation showcase with exterior and interior films, room galleries, and a morning/evening comparison.

## Hosting

Publish the `docs` directory through GitHub Pages (branch `main`, folder `/docs`). All asset paths are relative, so the showcase also works under a GitHub project subpath. `.nojekyll` keeps the files unchanged.

## Experience

- Nine short, silent films from two demonstration recordings.
- Responsive layouts and keyboard-accessible room selectors and galleries.
- A custom video player with playback, seeking and fullscreen controls.
- No download links, downloadable brochure or download controls in the interface.
- The closing section states “Starting from ₹10 Lakhs”.

Media are supplied demonstration assets. Project and source branding have been removed from the displayed visuals. This is an illustrative demo, not a property sales listing. Serving media on a public website does not prevent a technically knowledgeable visitor from saving publicly delivered assets.

No third-party analytics, external fonts, framework, build step, login or contact form is used.
